# 三分钟演示讲稿

公网入口见 `docs/PUBLIC-DEMO.md`，访问码由项目所有者单独提供。录制前确保授权有效、额度充足；录制中不要展示本地 `.env`、私钥、登录 token 或访问码输入。

| 时间 | 页面与动作 | 讲稿 |
|---|---|---|
| 0:00–0:20 | 控制台与 Monad Testnet 标记 | “这是 AgentPassport。用户在不同 AI 应用间重复提供背景，但共享全部历史又会暴露私密信息。我们让指定记忆在用户控制下跨应用使用。” |
| 0:20–0:45 | 研究助手、记忆保险箱 | “研究助手把背景、偏好和私密笔记分别保存。正文用 AES-GCM 加密，链上只记录密文承诺。当前 Vault 托管解密密钥。” |
| 0:45–1:10 | 创建写作授权，不选私密笔记 | “授权绑定到具体应用和具体记忆，有有效期与读取次数。本次只允许写作助手读取背景和偏好。” |
| 1:10–1:30 | 独立写作窗口，测试私密访问 | “应用有自己的签名密钥，通过 SDK 独立查询 Monad。试图读取未授权的私密笔记时，协议拒绝，不返回正文。” |
| 1:30–2:00 | 运行 DeepSeek 写作 | “每次读取签署带 nonce 和期限的请求。Vault 等待链上接受后释放资料。DeepSeek 用获授权的上下文生成真实文章。” |
| 2:00–2:30 | 查看凭证、从链上核验 | “应用签署输出和自检结果，承诺留在 Monad。我们独立核验签名、交易、事件和结果哈希。它证明归属和完整性，不保证语义正确。” |
| 2:30–2:50 | 撤销授权，再次运行 | “撤销后新的读取失败。已披露的内容不会被抹去，历史凭证仍可核验。” |
| 2:50–3:00 | SDK / 钱包入口 | “用户自己的钱包可以注册并拥有 Agent；签名授权由中继支付 gas。其他应用可用同一 SDK 接入。我们希望让身份、记忆和授权真正跨应用复用。” |

真实钱包扩展已完成验收，可以用钱包自己的工作空间录制正式视频；也可以使用明确标注的托管演示账户录制协议流程。不要将模拟 provider 当作真实钱包录像。三分钟是本项目的演示建议，最终时长和格式以登录后的比赛提交页为准。
