# AgentPassport：用户可控的跨应用 AI 记忆

赛道：信任、身份与 AI 基础设施。

## 项目介绍

用户在研究助手里整理了项目背景，到写作助手却要重新解释；把完整历史交给新应用，又会暴露无关信息。AgentPassport 让用户通过自己的钱包拥有 Agent，并只分享指定记忆，约束接收应用、读取次数和有效期，随时撤销后续访问。

研究助手把项目背景、写作偏好和私密笔记分别保存为 AES-256-GCM 密文。Monad 保存身份、密文承诺、授权状态和签名凭证。写作助手通过共享 SDK 独立查询链上权限，签署带 nonce 和期限的读取请求；Vault 等待链上确认后释放获授权资料。DeepSeek 根据这些资料生成文章，输出与应用自检结果也被签名并锚定。

本项目已在 Monad Testnet 完成真实部署和用户钱包验收。用户在 Edge 使用 MetaMask 注册 Agent #2，保存记忆、签署授权、调用 DeepSeek、核验凭证并签署撤销。撤销后的新读取被拒绝，此前的凭证仍可验证。

## 为什么属于赛道四

我们把应用之间的信任问题落实为可验证的身份与访问能力：应用能确认请求签名属于谁、某段记忆是否允许读取，以及读取和输出是否具有对应链上记录。Monad 在核心授权流程中执行权限检查，支持不同应用独立核验；明文和模型推理留在链下。

## 演示看点

从研究应用保存资料，到用户按范围授权，再由另一应用读取并生成；随后独立验证交易、签名、事件和哈希，最后撤销并展示新读取被拒绝。评审可以通过 `JUDGES.md` 操作，也可以复核公开交易与验证 JSON。

## 当前边界与后续方向

MVP 使用自定义身份合约。Vault 托管解密密钥，尚未实现端到端加密；输出凭证证明归属与完整性，不证明 AI 推理正确。后续计划包括 ERC-8004 身份适配、用户侧密钥控制、事件恢复索引和独立质量验证。现有实现尚未宣称安全审计、吞吐测试或生产级多租户能力。
